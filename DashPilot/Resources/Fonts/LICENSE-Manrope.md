# Manrope

The four `Manrope-*.ttf` files in this folder are bundled with DashPilot unmodified, and are the
only font files the app ships. They belong to the app target; the widget extension bundles no font.

- Copyright 2019 The Manrope Project Authors (https://github.com/sharanda/manrope), as recorded in
  each file's `name` table.
- Licensed under the SIL Open Font License, Version 1.1. The full license text is `OFL.txt`, beside
  this file, and it is copied into the app bundle with the fonts.

`OFL.txt` is the license file Google Fonts publishes for Manrope
(`google/fonts`, `ofl/manrope/OFL.txt`), committed unchanged. Its copyright line names the project's
current home (`googlefonts/manrope`) and the year 2018; the files bundled here carry the 2019 notice
of the original repository, which no longer exists. The license terms are the same SIL Open Font
License 1.1 either way.

DashPilot's own source code is under the MIT License (`LICENSE` at the repository root). That license
does not apply to these font files, and the Open Font License does not apply to DashPilot's code.

When the fonts are updated, bring the matching `OFL.txt` in beside them unchanged.
